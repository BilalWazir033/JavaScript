 1. Why do we use ES6?

Before ES6, JavaScript could do most things, but some code was unnecessarily long and difficult to manage.

ES6 introduced features that make JavaScript:

easier to write
easier to read
better for large applications
better for handling data
better for asynchronous programming
closer to modern programming languages like Java, C++, Python, etc.
